## 1. 文档概述

### 1.1 文档目的

本文档对微点云平台（Web管理端）和微点溯源App（移动作业端）进行产品需求重制，明确两个产品的功能边界、模块定义、交互流程和验收标准，作为后续产品迭代和开发实施的统一基准。

### 1.2 适用范围

| 产品 | 端口 | 覆盖范围 |
|------|------|---------|
| 微点云平台 | Web（PC浏览器） | 发码、商品、溯源、防窜、防伪、数据中心、生产管理、渠道管理、用户中心 |
| 微点溯源App | 移动端（Android/iOS） | 登录、信息查询、码值管理、关联管理、外部标识管理、出入库管理 |

**不覆盖**：运营平台（后台管理）、渠道平台（渠道商门户）、微点鉴（消费者端App）。

### 1.4 术语表

| 术语 | 说明 |
|------|------|
| 微点码 | 微点公司的核心技术：微米级稀疏点阵防伪码 |
| 内部发码 | 微点云发码中心生成码值，客户在微点云完成全流程 |
| 外部发码 | 客户自有系统按规则发码，微点提供UKey/SDK授权 |
| 码值 | 微点码的数字标识，唯一对应一个产品 |
| 标识 | 码值的业务抽象，包含码值、关联商品、溯源模板等 |
| 标识绑定 | 将标识（码值）与具体商品SKU关联 |
| 溯源模板 | 定义扫码后展示的溯源信息结构和内容 |
| 打包关联 | 按包装层级（单品→盒→箱→托盘）建立码值关联关系 |
| UKey | 硬件加密设备，用于外部发码模式的授权计次 |
| .wdata | 内部发码模式的授权码包文件 |
| 外部标识/药监码 | 客户自有体系的标识码（如药监码、GS1条形码等） |

## 2. 产品定位与目标

### 2.1 产品定位

**微点云平台**：面向品牌企业的防伪溯源全链路SaaS管理平台，提供从赋码、商品管理、溯源信息配置、生产出入库到防窜防伪的一站式云端管理能力。

**微点溯源App**：微点云的移动端作业伴侣，面向仓库、生产、质检等现场人员，提供扫码作业（赋码、打包、出入库、稽查等）的移动化工具。

### 2.2 目标用户

| 用户角色 | 使用产品 | 核心任务 |
|---------|---------|---------|
| 企业管理员 | 微点云Web | 组织管理、权限配置、基础数据维护 |
| 运营/市场人员 | 微点云Web | 商品建档、溯源模板配置、数据查看 |
| 生产管理人员 | 微点云Web + 溯源App | 发码申请、打包规则配置、生产任务管理 |
| 仓库管理人员 | 微点云Web + 溯源App | 出入库管理、库存盘点、转仓调拨 |
| 质检人员 | 微点溯源App | 码值激活/作废、质量检测、稽查比对 |
| 市场稽查人员 | 微点溯源App | 窜货稽查、扫码验证、工厂内部稽查 |

### 2.3 核心价值主张

| 价值 | 说明 |
|------|------|
| 一码到底 | 从赋码到消费者扫码，全链路数据贯通 |
| 双模发码 | 同时支持内部发码（开箱即用）和外部发码（灵活集成） |
| 移动作业 | App覆盖所有现场扫码场景，替代纸质单据 |
| 智能防窜 | 自动窜货预警+稽查工具，保护渠道秩序 |
| 数据驱动 | 扫码数据可视化，为市场决策提供数据支撑 |

### 3.3 两种发码模式的产品映射

| 功能模块 | 内部发码（微点云路线） | 外部发码（客户系统路线） |
|---------|---------------------|---------------------|
| 码值生成 | 微点云发码中心生成 | 客户自有系统按规则生成 |
| 授权方式 | .wdata授权码包 | UKey计次 / SDK按年授权 |
| 标识管理 | 标识申请→审批→下载 | 客户产品标识→订单→码库 |
| 适用场景 | 使用微点云追溯系统 | 自有追溯系统的集成方 |
| IT复杂度 | 低（开箱即用） | 高（需对接SDK/UKey） |
| 码值所有权 | 存在于微点云 | 客户自主管理 |
| 绑定方式 | 云平台直接绑定 | 码值回传或App关联 |

## 5. 微点云平台 Web端 — 功能需求

### 5.1 发码中心

#### 5.1.1 内部发码

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 标识概览 | P0 | 查看内部发码的标识信息概览，展示标识申请、绑定情况、使用状态等汇总数据 | 列表展示标识编号、类型、申请数量、已绑定数、可使用数、状态 |
| 标识申请 | P0 | 提交内部发码标识申请订单 | 支持填写标识类型、标识等级、包装单位、数量；审批通过后可下载或禁用；上传关联数据（.xlsx/.txt）时校验行数与数量是否一致 |
| 码库管理 | P0 | 申请下载内部发码码包（.wdata），用于码图绘制 | 支持按订单下载码包文件；下载后可正式解码授权 |
| 外部字段上传记录 | P1 | 查看微点码与外部字段关联关系的上传记录 | 列表展示上传时间、文件名、关联数量、状态；可追溯上传异常 |

**需增强项**（相对于现有功能清单）：
- 标识申请列表增加【文件名前缀备注】字段，支持按该字段搜索
- 标识申请增加【标识类型】、【包装单位】字段展示
- 审批通过的订单支持「撤销」或「禁用」操作，禁用后无法下载文件
- 关联数据上传时增加行数校验

#### 5.1.2 外部发码

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 客户产品标识 | P0 | 查看企业不同产品的产品标识号 | 列表展示产品标识号、产品名称、状态、创建时间；支持查看同一企业同一产品的不同规格 |
| 订单管理 | P0 | 外部发码订单的新增、查看、导出 | 支持填写UKey充值数量、选择UKey、提交审批；列表支持日期范围搜索；支持导出Excel全字段 |
| 物料管理 | P1 | 维护物料信息，用于排版制图时的物料选择 | 支持新增/编辑/停用物料；字段包含物料名称、规格、类型 |
| 自由编码码库 | P0 | 申请下载外部发码码包，用于码图绘制 | 列表显示【外部订单号】、【产地】字段；支持按这些字段筛选 |
| 制图模板 | P1 | 查看码图生成的模板配置 | 展示模板名称、参数、预览图 |
| 编码规则 | P0 | 维护外部发码的编码规则 | 支持自定义码值编码前缀、长度、规则启用/禁用 |
| 制码模板 | P1 | 管理制码参数模板 | 支持新增/编辑CD值、DPI、版本等参数 |
| 链接前缀配置 | P2 | 配置扫码跳转链接的前缀域名 | 支持添加/编辑链接前缀；扫码时自动拼接 |
| 导出链接 | P2 | 导出码值的访问短链接 | 按码段生成可扫描的短链接，支持批量导出 |
| 外部字段 | P1 | 为码值关联外部自定义字段（文本/图片/链接） | 支持上传外部字段数据（Excel/TXT）；扫码展示时显示外部字段内容 |

#### 5.1.3 标识绑定

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 标识绑定 | P0 | 将标识与商品关联 | 选择标识段→选择商品→确认绑定；支持批量绑定 |
| 取消赋码 | P0 | 取消商品与码值的关联关系 | 输入码值范围→取消绑定；已出库状态的码值需先解除出库 |

#### 5.1.4 码值查询

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 码值查询 | P0 | 查询单个码值的全链路信息 | 展示码值基本信息、关联商品、溯源信息、出入库记录、操作日志；操作日志包含替换操作记录 |

#### 5.1.5 外部标识赋码

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 外部标识赋码 | P0 | 将外部标识（如药监码）与商品关联 | 列表展示状态（已赋码/已关联/已打包/已入库/已出库）；支持按状态搜索；支持按包装单位筛选 |

**需增强项**：
- 状态显示字段，按终态统计（唯一状态原则：已赋码<已关联<已打包<已入库<已出库）
- 增加【标识关联清单】页面，展示码值成对显示（微点码+外部标识）

### 5.2 商品中心

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 品牌管理 | P0 | 品牌信息统一维护 | 卡片式展示品牌Logo、名称、编号、状态；支持新增/编辑/查询 |
| 商品管理 | P0 | 商品SKU信息维护 | 字段：品牌、商品编码、商品名称、品类、有效期、生产标准、包装单位、商品图片；支持导入/导出 |
| 包装单位 | P0 | 商品包装层级定义 | 类型：微点码、外部码等；可设置数值前缀；支持多级包装层级（例：1罐=10盒=10箱=10托盘） |

### 5.3 溯源中心

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 展示模板管理 | P0 | 配置扫码后消费者看到的商品展示页面 | 支持上传底图、Logo、配置展示信息、扫码提示语、跳转链接 |
| 溯源模板管理 | P0 | 定义商品溯源信息的采集和展示模板 | 支持自定义溯源环节（原料→生产→加工→质检→物流→销售）；每个环节可配置字段类型（文本/图片/日期/枚举） |
| 溯源绑定管理 | P0 | 将标识与溯源模板关联 | 支持按商品/品牌/批次绑定溯源模板；支持预览效果 |
| 数据采集 | P1 | 查看已采集的溯源环节数据 | 按码值/批次查询各环节采集结果的明细 |
| 图库 | P1 | 存储溯源展示中用到的图片素材 | 支持上传/管理/删除图片 |
| 海报页配置 | P2 | 配置扫码后的品牌海报展示页 | 支持品牌海报图片上传、跳转链接配置 |

**需增强项**：
- 溯源环节配置中，当数据类型为图片时，增加「允许长按保存」选项

### 5.4 防窜中心

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 窜货稽查 | P0 | 查看窜货稽查信息和处理记录 | 列表展示稽查时间、码值、经销商、判定结果、处理状态 |
| 窜货预警 | P0 | 设置和查看窜货预警规则与预警记录 | 支持设置扫码次数阈值、跨区域销售预警；达到阈值时触发通知（邮件/系统消息） |
| 窜货记录 | P0 | 商品窜货历史记录查询 | 展示窜货码值、涉及经销商、窜货区域、窜货次数、处理状态 |

### 5.5 数据中心

| 功能项 | 优先级 | 描述 | 验收标准 |
|--------|--------|------|---------|
| 扫码次数视图 | P0 | 扫码数据可视化分析 | 累计扫码次数、标识数量、溯源次数；扫码趋势图；地区排名TOP10 |
| 扫码记录 | P0 | 企业所有码值的扫码明细 | 展示扫码时间、码值、地点、设备；支持按码值精确查询 |
| 窜货视图 | P0 | 窜货数据可视化 | 经销商窜货排名、窜货批次分析、窜货预警趋势、窜货记录列表 |
| 微点发码标识申请数量 | P1 | 查看内部发码标识申请数量统计 | 按时段展示申请量、审批量、下载量 |
| 商品数量 | P1 | 查看所属品牌的商品数量统计 | 按品牌/品类统计商品SKU数 |
| 生产检测比对记录 | P1 | 微点码与外部二维码的内容比对记录 | 记录比对时间、码值、比对结果（一致/不一致） |

## 7. 核心业务流程

### 7.1 端到端流程：内部发码（SaaS标准路线）

```
企业注册/开通
  ↓
用户中心配置（组织→岗位→角色→用户）
  ↓
商品建档（品牌→商品→包装单位）
  ↓
溯源配置（展示模板→溯源模板→溯源环节）
  ↓
标识申请（发码中心→内部发码→标识申请）
  ↓
标识审批（企业管理员审核）
  ↓
标识绑定（标识→商品SKU关联）
  ↓
溯源绑定（标识→溯源模板关联）
  ↓
打包规则配置（打包关系管理）
  ↓
制图/赋码（微点制图软件 or SDK）
  ↓
↓ 可选 ↓
扫码激活 → 打包关联 → 入库 → 出库 → 发货
  ↓
消费者扫码（溯源展示 + 防伪验证）
```

### 7.2 端到端流程：外部发码（集成路线）

```
企业注册/开通
  ↓
UKey申领 → 授权烧录
  ↓
编码规则配置（客户自定义）
  ↓
订单管理 → 码包下载
  ↓
客户系统生码（客户自有规则）
  ↓
[可选] 码值回传微点云
  ↓
SDK制图 → 印刷/喷码
  ↓
[可选] 外部标识绑定关联
  ↓
流向数据回传 → 窜货监控
```

### 7.3 App现场作业流程

```
登录App
  ↓
扫码入库/出库/转仓
  ↓
打包关联（建立包装层级关系）
  ↓
↓ 可选 ↓
码值查询/批次查询（核实信息）
窜货稽查（市场稽查）
质量检测（印刷品控）
数据采集（溯源信息采集）
```

### 8.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|

| 要求 | 说明 |
|------|------|
| 权限控制 | RBAC模型，菜单级+按钮级权限 |
| 数据隔离 | 企业间数据严格隔离（多租户） |
| 传输加密 | HTTPS/TLS 1.2+ |
| 登录安全 | 验证码/密码错误锁定/会话超时 |
| UKey安全 | 硬件级加密，防克隆、防篡改 |
| 操作审计 | 所有操作记录日志，可追溯 |

### 8.3 可用性要求

| 要求 | 说明 |
|------|------|

| App离线能力 | 扫码基础功能支持离线模式（先缓存后同步） |
| Web浏览器兼容 | Chrome 80+ / Edge 80+ / 微信内置浏览器 |

### 8.4 可扩展性
